# เชื่อมแอปเช็คอินเข้ากับ Google Sheet

ทำครั้งเดียว ประมาณ 5 นาที

1. เปิด Sheet ที่จะเก็บข้อมูล แล้วไปที่เมนู **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิมใน `Code.gs` แล้ววางโค้ดจากไฟล์ [Code.gs](Code.gs) ทั้งหมด แล้วกดบันทึก (ไม่ต้องใส่ Sheet ID เพราะสคริปต์ผูกกับ Sheet นี้อยู่แล้ว)
3. (ไม่บังคับ) ตั้งรหัสลับที่บรรทัด `const TOKEN = ''` เช่น `'kku2569'`
4. เลือกฟังก์ชัน **setup** ที่แถบด้านบน แล้วกด **Run** ครั้งแรก Google จะขอสิทธิ์เข้าถึง Sheet และ Drive ให้กดอนุญาต
   - ระบบจะสร้างแท็บ `สรุปรายเดือน` `สรุปรายวัน` แท็บรายภาค `เช็คอิน` `จุดทำงาน` พร้อมจัดรูปแบบ และสร้างโฟลเดอร์ `รูปเช็คอินเซลฟี่` ใน Drive ให้อัตโนมัติ
   - รัน setup ซ้ำได้ทุกเมื่อ ข้อมูลในแท็บ `เช็คอิน` ไม่หาย (แท็บ `ลงเวลา` เดิมจะถูกเปลี่ยนชื่อเป็น `เช็คอิน`)
5. กด **Deploy → New deployment**
   - ประเภท: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
6. เปิดแอป ไปที่แท็บ **ตั้งค่า → Google Sheet** วาง URL และรหัสลับ (ถ้าตั้งไว้) แล้วกด **ทดสอบการเชื่อมต่อ**

ถ้าแก้โค้ดใน Apps Script ภายหลัง ให้ไปที่ **Deploy → Manage deployments → แก้ไข (ไอคอนดินสอ) → Version: New version** URL จะยังเป็นอันเดิม

ถ้าไม่อยากกรอก URL ในมือถือทุกเครื่อง ให้ใส่ไว้ที่บรรทัด `const SHEET_URL_DEFAULT = ''` ใน `index.html` ก่อนอัปขึ้น GitHub

## คอลัมน์ใน Sheet

ID · วันที่ · เวลา · ประเภท · ชื่อ · สถานที่ · ระยะจากจุดใกล้สุด (ม.) · อยู่ในจุดที่บันทึก · ละติจูด · ลองจิจูด · หมายเหตุ · รูป · ทดสอบ · บันทึกเมื่อ · ภาค

เมื่อแก้ไขหรือลบรายการในแอป แถวใน Sheet จะเปลี่ยนตามโดยอ้างอิงจากคอลัมน์ ID (Sheet เก็บเฉพาะค่าล่าสุด ไม่แสดงว่าแก้ไข) แต่ถ้าแก้ใน Sheet โดยตรง ข้อมูลในแอปจะไม่เปลี่ยนตาม

## แท็บใน Sheet

| แท็บ | ใช้ทำอะไร |
|---|---|
| สรุปรายเดือน | จำนวนวันที่เช็คอิน จำนวนครั้ง เวลาเช็คอินครั้งแรกเฉลี่ย และสถานที่ที่ไป (คำนวณเอง) |
| สรุปรายวัน | วันละหนึ่งแถว: สถานที่ เวลาเช็คอินครั้งแรก เวลาเช็คเอาท์ล่าสุด จำนวนครั้ง และหมายเหตุ (คำนวณเอง) |
| ส่วนกลาง / ภาคเหนือ / ภาคตะวันออกเฉียงเหนือ / ภาคใต้ / ภาคตะวันออก | รายการเช็คอินของแต่ละภาค (จัดตามจังหวัดของสถานที่) เรียงใหม่สุดก่อน มีลิงก์ดูรูป พร้อมจำนวนวัน จำนวนครั้ง และวันล่าสุด |
| อื่นๆ | เช็คอินจากจังหวัดที่ไม่อยู่ในภาคข้างต้น |
| เช็คอิน | ข้อมูลดิบจากแอป: วันเวลา สถานที่ (ชื่อจุดที่บันทึกไว้ หรือ ตำบล อำเภอ จังหวัด) พิกัด และภาค ตัวเทาเอียงคือโหมดทดสอบ (ไม่นับในสรุป) |
| จุดทำงาน | รายชื่อจุดทำงานพร้อมลิงก์แผนที่ ใช้อ้างอิง |
| สรุปการลา | แถวละหนึ่งคนต่อเดือน: ชื่อผู้ลา จำนวนวันลาป่วย ลาพักผ่อน รวม และวันที่ที่ลา พร้อมยอดรวมทั้งปีด้านบน |
| การลา | ข้อมูลดิบจากแอป หนึ่งแถวต่อหนึ่งวันลา พร้อมชื่อผู้ลา |

สองแท็บสรุปเป็นสูตรทั้งหมด ไม่ต้องกรอกเอง ถ้าเผลอแก้สูตรเสีย ให้รัน `setup` อีกครั้ง

## ลบข้อมูลใน Sheet

ใช้เมนู **ระบบเช็คอิน** ที่แถบเมนูของ Sheet (ขึ้นเองเมื่อเปิด Sheet) อย่ากดปุ่ม Delete ที่แถวโดยตรง เพราะคอลัมน์ที่ซ่อนไว้จะยังมีค่าค้างอยู่

- **ลบแถวที่เลือก:** เปิดแท็บ `เช็คอิน` หรือ `การลา` เลือกแถว (ลากคลุมหลายแถวได้) แล้วกดเมนูนี้
- **ลบข้อมูลทั้งเดือน…:** พิมพ์เดือน/ปี เช่น `10/2569` ระบบลบทั้งเช็คอินและการลาของเดือนนั้น และย้ายรูปไปถังขยะใน Google Drive (กู้คืนได้ภายใน 30 วัน)
- **เก็บกวาดแถวที่ลบไม่หมด:** ลบแถวที่ไม่มีวันที่แต่ยังมีค่าค้างในคอลัมน์ที่ซ่อน

การลบใน Sheet ไม่ลบข้อมูลในแอปบนมือถือ (แอปเก็บประวัติของตัวเองไว้ในเครื่อง)

## หัวหน้าแก้ข้อมูลใน Sheet

- **แก้ที่แท็บ `เช็คอิน` (หรือ `การลา`) เท่านั้น:** เช่น แก้เวลาเมื่อมีคนลืมเช็คอินหรือเช็คอินช้า แท็บสรุปและแท็บรายภาคจะคำนวณตามทันที ส่วนแท็บสรุปจะขึ้นคำเตือนถ้ามีคนพยายามพิมพ์ทับ
- **เพิ่มแถวเองได้:** กรอก วันที่ (เช่น `2026-10-06` หรือ `6/10/2026`), เวลา, ประเภท (`เช็คอิน` / `เช็คเอาท์`), ชื่อ, สถานที่ ระบบเติม ID และภาคให้เอง (ถ้าเว้นประเภทไว้ จะใส่เป็น `เช็คอิน`)
- **ค่าที่หัวหน้าแก้ไม่ถูกทับ:** ในแอปแก้ได้แค่เวลาของรายการเช็คเอาท์ และจะเขียนทับเฉพาะช่องวันที่/เวลาของแถวนั้น

## ใบลงชื่อปฏิบัติงาน (ไฟล์แยก ดาวน์โหลดเป็น Excel)

ใบลงชื่อรายเดือนแบบฟอร์มเดิม หนึ่งแท็บต่อหนึ่งคน อยู่ในไฟล์ Google Sheet อีกไฟล์

1. ใส่ ID ของไฟล์ใบลงชื่อใน `SIGN_SHEET_ID` แล้วกด Run ฟังก์ชัน `setupSignSheet` หนึ่งครั้ง ไฟล์จะมีแท็บ `ตั้งค่า` `รายชื่อ` `วันหยุด` และเมนู **ใบลงชื่อ**
2. แท็บ `ตั้งค่า`: เลือกเดือนและปี (พ.ศ.) แก้หัวกระดาษของแต่ละภาคและผู้ลงนามรับรองได้
3. เมนู **ใบลงชื่อ → สร้าง/อัปเดตใบลงชื่อ**: ดึงเวลาจากแท็บ `เช็คอิน` และ `การลา` ของไฟล์หลัก
   - เวลาเข้างาน = เช็คอินแรกของวัน, เวลาออกงาน = เช็คเอาท์สุดท้ายของวัน
   - ช่องลงชื่อเข้า/ออกงาน = "เช็คอินผ่านระบบ" / "เช็คเอาท์ผ่านระบบ" กดแล้วเปิดรูปเซลฟี่
   - หมายเหตุ = ประเภทการลา, ชื่อวันหยุด หรือวันเสาร์/อาทิตย์ (แถวสีเทา)
   - ชื่อใหม่ที่เจอจะถูกเพิ่มในแท็บ `รายชื่อ` เอาเครื่องหมายช่อง "ทำใบลงชื่อ" ออกถ้าไม่ต้องทำให้คนนั้น
4. ดาวน์โหลด: ไฟล์ → ดาวน์โหลด → Microsoft Excel (.xlsx)

แท็บ `วันหยุด` ใส่ไว้เฉพาะวันหยุดที่วันที่ตายตัว วันหยุดทางพุทธศาสนา วันหยุดชดเชย และวันหยุดพิเศษต้องเพิ่มเอง
