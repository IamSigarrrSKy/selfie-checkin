# เช็คอินเซลฟี่

เว็บแอปเช็คอินแจ้งตำแหน่งด้วยรูปเซลฟี่และ GPS

- ถ่ายเซลฟี่จากกล้องหน้า ระบบพิมพ์เวลา พิกัด และชื่อจุดทำงานลงบนรูป
- บันทึกสถานที่: ชื่อจุดที่บันทึกไว้ถ้าอยู่ในรัศมี ไม่งั้นเป็น ตำบล อำเภอ จังหวัด จาก OpenStreetMap
- ส่งข้อมูลเข้า Google Sheet และเก็บรูปใน Google Drive ผ่าน Apps Script ดูวิธีตั้งค่าที่ [apps-script/README.md](apps-script/README.md)
- แก้ไขหรือลบรายการย้อนหลังได้ ส่งออก CSV ได้

เปิดใช้งานผ่าน GitHub Pages (ต้องเป็น https กล้องและ GPS จึงจะทำงาน)
