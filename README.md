# เช็คอินเซลฟี่

เว็บแอปเช็คอินแจ้งตำแหน่งด้วยรูปเซลฟี่และ GPS

- ถ่ายเซลฟี่จากกล้องหน้า ระบบพิมพ์เวลา พิกัด และชื่อจุดทำงานลงบนรูป
- บันทึกสถานที่: ชื่อจุดที่บันทึกไว้ถ้าอยู่ในรัศมี ไม่งั้นเป็น ตำบล อำเภอ จังหวัด จาก OpenStreetMap
- ส่งข้อมูลเข้า Google Sheet และเก็บรูปใน Google Drive ผ่าน Apps Script ดูวิธีตั้งค่าที่ [apps-script/README.md](apps-script/README.md)
- แก้ไขหรือลบรายการย้อนหลังได้ ส่งออก CSV ได้

เปิดใช้งานผ่าน GitHub Pages (ต้องเป็น https กล้องและ GPS จึงจะทำงาน)

## ลิงก์ใช้งาน

| ลิงก์ | การใช้งาน |
|---|---|
| A: https://iamsigarrrsky.github.io/selfie-checkin/ | ใช้ GPS จริงเท่านั้น เช็คอินได้เฉพาะในรัศมีของจุดที่กำหนด ถ่ายเซลฟี่สดเท่านั้น |
| B: https://iamsigarrrsky.github.io/selfie-checkin/?b | ปักหมุดเองได้ อัปโหลดรูปจากเครื่องได้ เช็คอินได้ทุกที่ แก้จุดทำงานและตั้งค่า Sheet ได้ |

ทั้งสองลิงก์ใช้ Sheet เดียวกัน คอลัมน์ "ลิงก์" ในแท็บ `เช็คอิน` บอกว่ารายการมาจากลิงก์ไหน

## แดชบอร์ด

`dashboard.html` แสดงสรุปรายเดือนจากข้อมูลใน Sheet: เช็คอินวันนี้ แผนที่ กราฟรายวัน แยกตามภาค สรุปรายคน และการลา

https://iamsigarrrsky.github.io/selfie-checkin/dashboard.html ต้องใส่รหัสผ่าน (ตั้งใน `DASH_PASSWORD` ตอนวางโค้ดใน Apps Script ไม่ได้เก็บใน GitHub) เครื่องที่ใส่ถูกแล้วจะจำไว้
